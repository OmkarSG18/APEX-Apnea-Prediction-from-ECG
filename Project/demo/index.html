How It Works

1. Single-lead ECG is segmented into 60-second windows.

2. R-peaks detected using Pan-Tompkins algorithm.

3. 14 features extracted (HRV + Wavelet + EDR).

4. 5-minute sliding window context (lags -2 to +2) is appended.

5. Soft Voting Ensemble classifies segment with calibrated decision threshold (p=0.31).

About APEX
Apnea Prediction from ECG using Explainable ML — aligned with UN SDG 3
Project Overview

Sleep apnea affects over 1 billion people yet remains underdiagnosed due to the cost of PSG. The APEX project demonstrates that single-lead ECG + Soft Voting Ensemble ML reaches 85.06% accuracy and 95.73% sensitivity, advancing SDG Goal 3: Good Health and Well-Being.
